## Steps to connect IBM MQ Queue Manager Remotely using Client Mode

* Create an OS group : *appgrp* and create user : *appusr*, add the user to this group. Create the password for the user as Pass@1234 (change as per the standards).

[source, bash]
-----
sudo groupadd appgrp

sudo useradd -m -s /bin/bash appusr

sudo passwd appusr

sudo usermod -aG appgrp appusr

groups appusr
-----

* Now create the queue manager with mqm user using the command: *crtmqm APPQM*, after creating the queue manager start the queue manager using the command *strmqm APPQM*

* Now we should provide the below permissions to the OS group and Queue Manager created from command prompt using mqm user, here we are providing the queue name should start with *APP*, so create application queues with name starting with *APP*:

[source, bash]
-----
setmqaut -m APPQM -t qmgr -g appgrp +connect +inq

setmqaut -m APPQM -n APP.** -t queue -g appgrp +put +get +browse +inq
-----
